# MP3 可视化播放器

一款用 Rust 开发的 MP3 图形化播放器原型，侧重**鼓点节奏的采集、计算与可视化呈现**。基于 eframe/egui 即时模式绘制，配合 rodio 播放与 symphonia 解码，实时 FFT 分析驱动十种可视化模式。

## 功能特性

- **鼓点专项分析**：低/中/高频能量包络 + 自适应阈值，识别 Kick / Snare / Hi-hat 并估计 BPM，视觉反馈与实际鼓点对齐。
- **十种可视化模式**：双盘、单盘、炫彩、粒子流、歌词、炫彩光带、频谱、波形、混合、节奏，界面下拉即切即生效。
- **5 套主题色系**：经典彩虹、霓虹、极光、暖焰、单色，切换时整屏换色。
- **歌词展示**：支持 `.lrc`（带时间轴）与 `.txt`（纯文本按人声能量启发式自动对齐）；播放时自动查找同目录同名歌词文件，也可手动选择。
- **区域录屏**：一键只录中央「动效 + 歌词」区域并内嵌当前曲目声音，输出带音轨的 H.264/AAC MP4。
- **炫彩光带**：白色透视空间网格背景（消失点放射纵线 + 加密横线 + 远近浓淡），一条随音波与节拍跳动的炫彩曲线，震动时甩出渐隐粒子。

## 技术栈

| 用途 | 依赖 |
| --- | --- |
| GUI | `eframe` / `egui` 0.29 |
| 音频解码 | `symphonia`（mp3 / isomp4 / flac / wav / ogg） |
| 音频播放 | `rodio` 0.20 |
| FFT 分析 | `rustfft` 6 |
| 文件对话框 | `rfd` 0.15 |

分析参数：`FFT_SIZE = 2048`，1,024 个 bin 按对数频率归并成 `BANDS = 256` 段频谱柱。

## 环境要求

- Rust 1.70+（edition 2021）
- Windows（录屏功能使用 GDI 抓帧，依赖 Windows API）
- 录屏需额外安装 [ffmpeg](https://ffmpeg.org/)，并确保其在 `PATH` 中（仅录屏时需要）

## 构建与运行

```bash
# 调试构建并运行
cargo run

# 发布构建（opt-level = 3）
cargo build --release
./target/release/mp3-visualizer.exe
```

程序启动后通过顶部 **＋文件 / ＋文件夹** 添加音乐，**♫ 歌词** 手动载入歌词；播放控制与进度条在底部。

## 使用说明

- **添加音乐**：顶部「＋文件」选择单个音频，或「＋文件夹」批量导入（异步加载，避免卡顿）。
- **播放控制**：底部 `⏮ / 播放暂停 / ⏭`，进度条可点击或拖拽跳转。
- **切换模式 / 主题**：画布上方两个下拉框，分别选择可视化模式与配色色系。
- **歌词**：播放时自动查找同目录同名 `.lrc` / `.txt`；也可点「♫ 歌词」手动选择。
- **录屏**：底部「● 录屏」开始（红点 + 计时），再次点击停止；视频保存到工作目录下的 `recordings/`。
- **灵敏度 / 音量**：界面滑块实时调节。

## 环境变量（验证 / 演示用）

| 变量 | 作用 |
| --- | --- |
| `MP3_VIZ_MODE=Ribbon` | 指定启动模式（用枚举名，如 `Dual` / `ParticleFlow` / `Ribbon`） |
| `MP3_AUTO_DEMO=1` | 启动时自动加载演示曲并播放 |

`tools/` 目录内含演示音频 `demo_beat.wav` 与歌词 `demo_beat.lrc`，以及生成/截图辅助脚本。

## 项目结构

```
src/
  main.rs       程序入口与窗口配置
  app.rs        主应用：界面、模式分发、交互、录屏控制
  analysis.rs   FFT / 频段归并 / 鼓点检测与 BPM 估计
  audio.rs      音频解码与播放引擎
  lyrics.rs     LRC 解析与歌词自动对齐
  particles.rs  粒子流模式
  ribbon.rs     炫彩光带模式（透视网格 + 光带 + 粒子）
  recorder.rs   区域录屏与 ffmpeg 编码
  theme.rs      配色色系与渐变色带
  ui_style.rs   UI 语义 token
```
